# Mali Up Web

This app is the public-facing product site for Mali Up Business Edition. It mirrors the premium fintech white direction while the mobile app remains the main MVP surface.

## What’s In The App

- Product landing page for Mali Up B v1.0.
- Feature sections that explain the business-only scope.
- Premium visual language aligned with the mobile app branding.
- A future-friendly shell that can later support dashboard or onboarding content.

## Getting Started

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Notes

- Keep the UI aligned with the Premium Fintech White system used in the mobile app.
- The current brand language should stay Swahili-first in content and copy where possible.
- This app should support the current launch story, not the old hybrid v2.0 positioning.
