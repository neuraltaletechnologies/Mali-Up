## Error Messages (Critical for UX)

### Validation Errors

| Scenario | Message | Guidance |
|----------|---------|----------|
| Required field | "Tafadhali jaza sehemu hii" | Field is mandatory |
| Invalid email | "Tafadhali ingiza barua pepe sahihi (mfano: jina@example.com)" | Show format example |
| Invalid phone | "Tafadhali ingiza namba sahihi (mfano: 0712345678)" | Show example number |
| Password weak | "Nenosiri lazima liwe na herufi 8 au zaidi na nambari" | Password too simple |

### Network Errors

| Scenario | Message | Action |
|----------|---------|--------|
| No connection | "Hakuna muunganisho. Tafadhali angalia WiFi au data yako" | Check network |
| Timeout | "Kumekuwa na muda mrefu. Tafadhali jaribu tena" | Retry action |
| Server error | "Kosa la serikali. Tafadhali jaribu baadaye" | Try later |

| Format | Example | Rules |
|--------|---------|-------|
| Standard | TSh 150,000.00 | Use space for thousands |

## Tone & Style Guidelines

**RULE:** Use semi-formal throughout Mali Up - professional but friendly

Always use "Tafadhali" (please) when:
- Making requests
- Asking for input
- Warning about actions
- Guiding users

Error messages should GUIDE, not CONFUSE:

**Good (user-friendly guidance):**
- "Ankara haipo. Jaribu tafuta tena." (Invoice not found. Try searching again)
- "Tafadhali ingiza namba sahihi (mfano: 0712345678)" (Please enter valid number like: 0712345678)
