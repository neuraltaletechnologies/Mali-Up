# Mali Up Kiswahili-First UX - Developer Style Guide

**Purpose:** Ensure consistent, high-quality Kiswahili implementation across all platforms  
**Last Updated:** May 24, 2026  

---

## Before You Start

This is NOT a translation guide. This is a **localization guide** for building Kiswahili-first experiences.

**Key Principle:** Native Kiswahili first → English as fallback

Every screen, every error, every flow must be designed for Kiswahili speakers first. English translations should feel natural, not like they were generated by machine.

---

## Translation File Structure

### Standard Format

All translation files use this nested JSON structure:

```json
{
  "namespace": {
    "key": "Translated string",
    "nested": {
      "key": "Value"
    }
  }
}
```

### Namespace Organization

| Namespace | Purpose | Files |
|-----------|---------|-------|
| `common` | Navigation, buttons, shared UI | Used in all apps |
| `finance` | Invoices, payments, accounting | Mobile, Web, Backend |
| `inventory` | Products, stock, categories | Mobile, Web, Backend |
| `reporting` | Dashboards, charts, analysis | Mobile, Web |
| `compliance` | Privacy, consent, audit | Mobile, Web, Backend |
| `business` | Business ops, users, roles | Mobile, Web, Backend |
| `errors` | Validation, network, auth | Mobile, Web, Backend |
| `emptyStates` | No data messages | Mobile, Web |
| `dates` | Month names, time | Mobile, Web, Backend |
| `auth` | Login, signup, passwords | Mobile, Web, Backend |
| `messages` | Success, notifications, guidance | Mobile, Web, Backend |

**Rule:** Namespaces must be consistent across all three platforms (mobile, web, backend).

## Implementation Patterns

### Flutter Mobile

**File Location:** `l10n/translations/{locale}.json`

**Usage in Code:**
```dart
import 'package:intl/intl.dart' as intl;

// Get translation
String title = translations['common']['home'] ?? 'Home';

// Format currency (TSh)
String price = CurrencyFormatter.formatCurrency(15000.50);
// Output: "TSh 15,000.50"

// Format date (DD/MM/YYYY)
String date = DateFormatter.formatDate(DateTime.now());
// Output: "24/05/2026"

// Format relative date
String relDate = DateFormatter.formatRelativeDate(
  DateTime.now().subtract(Duration(days: 1)),
  Locale('sw', 'TZ')
);
// Output: "Jana" (Yesterday in Kiswahili)
```

**Riverpod Provider for Locale:**
```dart
final localeProvider = StateNotifierProvider<LocaleNotifier, Locale>((ref) {
  return LocaleNotifier();
});

// Usage in widget:
Consumer(
  builder: (context, ref, child) {
    final locale = ref.watch(localeProvider);
    // Rebuild entire widget tree when locale changes
    return YourWidget();
  },
)
```

**Key Points:**
- Locale changes require full Riverpod rebuild (no hot reload)
- All dates use `DateFormatter.formatDate()` (DD/MM/YYYY)
- All currency uses `CurrencyFormatter.formatCurrency()` (TSh with space separator)
- Kiswahili is primary; English is fallback

### Next.js Web

**File Location:** `public/locales/{locale}/{namespace}.json`

**Usage in Code:**
```jsx
import { useTranslation } from 'next-i18next';

export function MyComponent() {
  const { t } = useTranslation('common');
  
  return (
    <div>
      <h1>{t('dashboard')}</h1>
      <button>{t('common:add')}</button>
    </div>
  );
}

// For static generation with i18n
export const getStaticProps: GetStaticProps = async ({ locale }) => {
  return {
    props: {
      ...(await serverSideTranslations(locale, ['common', 'finance'])),
    },
  };
};
```

**Formatting in Next.js:**
```jsx
// Dates
import { format } from 'date-fns';
import { sw } from 'date-fns/locale';

const formatted = format(new Date(), 'dd/MM/yyyy', { locale: sw });

// Currency
const formatted = new Intl.NumberFormat('sw-TZ', {
  style: 'currency',
  currency: 'TZS',
  minimumFractionDigits: 2,
  useGrouping: true,
}).format(15000.50);
// Output: "TSh 15,000.50"
```

**Key Points:**
- Locale routing: `/en/dashboard`, `/sw/dashboard`
- Use ISR (Incremental Static Regeneration) for translated pages
- All dates use `format()` with Tanzanian standard (DD/MM/YYYY)
- URL-based locale detection (highest priority)

### NestJS Backend

**File Location:** `services/{service}/src/locales/{locale}.json`

**Usage in Code:**
```typescript
import { I18nService } from '@common/i18n/i18n.service';
import { I18nMiddleware } from '@common/i18n/i18n.middleware';

@Controller('auth')
export class AuthController {
  constructor(private i18nService: I18nService) {}

  @Post('login')
  async login(@Req() req: Request) {
    // Get locale from middleware
    const locale = (req as any).i18n?.locale || 'en';
    
    // Translate error message
    const errorMsg = this.i18nService.t('errors.invalidLogin', locale);
    
    // Translate with parameters
    const msg = this.i18nService.tp(
      'inventory.availableStock',
      { count: 5 },
      locale
    );
  }
}

// Register middleware in main.ts
app.use(new I18nMiddleware(i18nService));
```

**Locale Detection (In Order):**
1. URL path: `/api/v1/sw/auth/login`
2. Query parameter: `?locale=sw`
3. Accept-Language header: `Accept-Language: sw-TZ, en;q=0.9`
4. Cookie: `locale=sw`
5. Default: `en`

**Key Points:**
- Inject `I18nService` into any service/controller
- Middleware automatically detects locale
- Use `tp()` for parameterized translations
- All error messages should be localized

## Content Guidelines

### Tone & Voice

**DO:**
- ✅ Use semi-formal, professional tone
- ✅ Always say "Tafadhali" (please) when asking
- ✅ Use context-aware error messages with guidance
- ✅ Write for Tanzanian business context
- ✅ Use natural Kiswahili (not English words)

**DON'T:**
- ❌ Use casual/slang Kiswahili
- ❌ Use literal English translations
- ❌ Use technical jargon without explanation
- ❌ Assume English context (dates, currency, etc.)
- ❌ Use machine translation terminology

### Business Terminology

Always refer to **TERMINOLOGY_DICTIONARY.md** for official terms.

| Concept | Kiswahili | NOT This |
|---------|-----------|----------|
| Invoice | Ankara | Ankara ya Bima (wrong) |
| Customer | Mteja | Mteja wa Duka (too specific) |
| Payment | Malipo | Fedha (too general) |
| Inventory | Hesabu ya Bidhaa | Duka ya Bidhaa (not exact) |
| Report | Ripoti | Ufafanuzi (wrong) |

**When in doubt, check the dictionary first.**

### Error Messages Must Educate

Never just say something is wrong. **Tell users how to fix it.**

**Bad:**
- "Invalid input"
- "Connection error"
- "Format not supported"

**Good:**
- "Tafadhali ingiza namba sahihi (mfano: 0712345678)" - Shows example
- "Hakuna muunganisho. Tafadhali angalia WiFi au data yako" - Suggests action
- "Sehemu hii haiwezi kuwa na zaidi ya 100 herufi" - Explains limit

### Empty States Guide Users

Never just say "No data." **Tell them what to do next.**

**Bad:**
- "No invoices"
- "Empty list"

**Good:**
- "Hakuna ankara. Anza kwa kuandika ankara mpya" - Tell them how to start
- "Hakuna mteja. Ongeza mteja wa kwanza" - Clear action

## Formatting Standards

### Dates

**Format:** `DD/MM/YYYY` (Tanzanian standard)

```
✅ 24/05/2026
✅ 01/01/2026
❌ 05/24/2026 (American format - NEVER)
❌ 2026-05-24 (ISO format - NOT for display)
```

**Full date with month name (semi-formal):**
```
Ijumaa, 24 Mei 2026
```

**Month names (Kiswahili):**
```
Januari, Februari, Machi, Aprili, Mei, Juni,
Julai, Agosti, Septemba, Oktoba, Novemba, Desemba
```

**Relative dates:**
```
Leo (Today)
Jana (Yesterday)
Kesho (Tomorrow)
Dakika 5 zilizopita (5 minutes ago)
```

### Currency

**Format:** `TSh {amount}` with space as thousand separator

```
✅ TSh 150,000.00
✅ TSh 1,000.50
✅ TSh 999.99
❌ Tsh 150000 (no separator)
❌ 150,000 TSh (symbol at end)
❌ $150,000 (wrong symbol)
```

**No currency in some contexts (internal):**
```
Input: 15000
Display: 15,000 (if amount only, add TSh elsewhere)
Calculation: Keep as number
```

### Numbers

**Thousand separator:** Space (not comma or period)

```
✅ 1 000 000
✅ 150 000
❌ 1,000,000
❌ 1.000.000
```

**Decimals:** Period (.)

```
✅ 150,000.50 (in currency)
✅ 0.50 (decimal amount)
❌ 150,000,50
```

### Phone Numbers

**Format:** 10 digits, no spaces

```
Display: 0712345678
Stored: 0712345678 (or +255712345678 for international)
Example in error: "mfano: 0712345678"
```

### Email

**Lowercase always:**
```
✅ user@example.com
✅ john@business.co.tz
❌ User@Example.com (mixed case)
```

## Platform-Specific Notes

### Flutter Mobile

- **Language switching:** Requires full Riverpod rebuild (restart entire widget tree)
- **No hot reload** when changing locale
- **Fonts:** Use system fonts (Roboto works fine with Kiswahili)
- **RTL:** NOT needed (Kiswahili is LTR like English)
- **Screen space:** Kiswahili text is ~20% longer than English - test layout

### Next.js Web

- **Routing:** `/en/dashboard` vs `/sw/dashboard` (locale in URL path)
- **Meta tags:** Must be in correct language (SEO important)
- **SSR vs ISR:** Use ISR for translated pages
- **Fonts:** Roboto or system fonts (Kiswahili compatible)
- **Language switcher:** Link to same page in different locale

### NestJS Backend

- **API responses:** Include `locale` in response header
- **Error codes:** English, but message translated
- **Timestamps:** Use ISO 8601 (2026-05-24T14:30:00Z)
- **Documentation:** Swagger/OpenAPI in English + Kiswahili examples

## Common Mistakes to Avoid

### ❌ Machine Translation

```javascript
// WRONG - Machine translated, unnatural
"Tafadhali ingiza barua pepe sahihi kwa muundo maalum"

// RIGHT - Natural business Kiswahili
"Tafadhali ingiza barua pepe sahihi (mfano: jina@example.com)"
```

### ❌ English Words in Kiswahili

```javascript
// WRONG - Mixed languages
"Ankara wa Invoice imefungwa" or "Dashboard inapakia"

// RIGHT - Pure Kiswahili
"Ankara imefungwa" or "Paneli inapakia"
```

### ❌ Wrong Date Format

```javascript
// WRONG - American format
const date = "05/24/2026";

// RIGHT - Tanzanian format
const date = "24/05/2026";
```

### ❌ Currency Formatting

```javascript
// WRONG
"TSh150,000" or "Tsh 150000"

// RIGHT
"TSh 150,000.00"
```

### ❌ English Error Messages

```javascript
// WRONG - Technical jargon
"Invalid input format" or "Connection timeout"

// RIGHT - User-friendly guidance
"Tafadhali ingiza namba sahihi (mfano: 0712345678)"
"Muunganisho hauwezi kufanya kazi. Tafadhali jaribu baadaye."
```

## Review Workflow

### Checklist for Pull Requests

When submitting UI with Kiswahili text:

1. **Terminology Review**
   - [ ] All business terms match TERMINOLOGY_DICTIONARY.md
   - [ ] No alternate terms used inconsistently

2. **Localization Review**
   - [ ] All visible strings in translation files
   - [ ] No hardcoded English strings in UI
   - [ ] English fallback available

3. **Formatting Review**
   - [ ] Dates: DD/MM/YYYY
   - [ ] Currency: TSh with space separator
   - [ ] Numbers: Space as thousand separator

4. **Tone & Voice Review**
   - [ ] Professional, semi-formal Kiswahili
   - [ ] Error messages include guidance
   - [ ] Consistent voice across screens

5. **Platform Review**
   - [ ] Mobile: No text truncation, Riverpod refresh works
   - [ ] Web: URL routing correct (/sw/... and /en/...)
   - [ ] Backend: Error messages localized

6. **Native Speaker Review**
   - [ ] Native Kiswahili speaker has reviewed
   - [ ] No machine translation detected
   - [ ] Cultural appropriateness confirmed
